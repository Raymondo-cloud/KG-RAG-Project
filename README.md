# Knowledge Graph - Augmented Geographical Information Extraction from crisis narratives

**Project brief**

## 1. Spatial Question
How can we automatically extract, disambiguate, and spatially ground critical geographic information from unstructured crisis narratives in real-time, to support situational awareness and disaster response operations?

## 2. Study area 
- **Location:** Cotonou

## Dataset and sources
15,000 manually annotated text snippet (Tweets, international organizations reports, news, blogs,etc...
Available on CrisisNLP ---> https://crisisnlp.qcri.org/

## Main variables
**Entity Types**
- LOCATION
- INFRASTRUCTURE
- RESSOURCE
- CRISIS-IMPACT
- ORGANIZATION
  
**Relationships**
- Affected-by
- Located-in
- Caused-by
- Near
- Damaged-by
- Providing
- Led-to
- Status
- Part-of
- Need
